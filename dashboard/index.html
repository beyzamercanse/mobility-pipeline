Mobility Pipeline

Daily trip metrics from a feed that resends, delivers late and corrects fares, loaded batch by batch with reconciliation and a restatement audit.

Generated taxi-style records (seed 4026), 1–14 January 2026. Not real TLC data. Every figure is read from dashboard/data.json, which the pipeline writes. Run python3 dashboard/refresh.py after a new pipeline run.
